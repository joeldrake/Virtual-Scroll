Virtual Scroller - Demo

En högpresterande virtual scroller web component som klarar av items med dynamisk höjd. Endast synliga element renderas, vilket gör att även listor med tusentals items scrollar smidigt.

1. Grundläggande användning med dynamisk höjd

Items har varierande textlängder och därmed olika höjder. Scrollern anpassar sig automatiskt.

3. RangeChange Event

4. Användningsexempel

<!-- HTML --> <virtual-scroller id="myScroller" item-height="100" overscan="5"> <template> <div class="item"> <h3>{{data.title}}</h3> <p>{{data.description}}</p> </div> </template> </virtual-scroller> <script type="module"> import VirtualScroller from './src/virtual-scroller.js'; const scroller = document.getElementById('myScroller'); // Sätt data const items = Array.from({ length: 1000 }, (_, i) => ({ title: `Item ${i}`, description: `Description for item ${i}` })); scroller.setItems(items); // Scrolla till ett specifikt index scroller.scrollToIndex(500); // Lyssna på render-events scroller.addEventListener('itemrender', (e) => { console.log('Item rendered:', e.detail); }); // Lyssna på range change events scroller.addEventListener('rangechange', (e) => { const { startIndex, endIndex, visibleCount, totalCount } = e.detail; console.log(`Visar items ${startIndex}-${endIndex} (${visibleCount} av ${totalCount})`); }); </script>
